# OSK.Petra.Godot.Primitives

Provides foundational data structures and essential Godot objects used throughout the Petra ecosystem. These data structures work within the Godot inspector and serializers!

Examples of primitive types in this library include:
* Guid Identifiers
* Timespans
* Nullable data (int, float, boolean, timespan, etc.)

## Petra Framework

See the [OSK Hub](https://opensourcekingdom.github.io/OSK.Hub/) or the [Petra Godot Framework](https://github.com/OpenSourceKingdom/OSK.Petra.Godot.Framework) for additional documentation and examples.
